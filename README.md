Entry for the make.fun competition **A Day of One-Line Pitches**
(`u-ronigrv-a-day-of-one-line-pitches-12cd9bb3`).

`main.ts` (Node 22, standard library only, no network) writes a single
sentence — at most 240 characters — that would convince a friend who has
never coded to let an AI agent build their first app idea on make.fun, to
`/output/entry.txt` (or `$ENTRY_OUTPUT_PATH` when set). The sentence is
validated before writing: 1–240 Unicode characters, not only whitespace.

> That app idea you've been carrying around? Just describe it on make.fun in your own words and an AI agent will build a first version you can tap and try — free to enter, and if it's not right, you've lost nothing but a few minutes.

Run it with:

```sh
node main.ts
```
